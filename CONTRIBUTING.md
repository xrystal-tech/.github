# Contributing to xrystal-tech repositories

Thanks for contributing. This file is the org default; individual repos may add repo-specific steps in their own `CONTRIBUTING.md`.

## Before you start

1. Read the [repository policy](policies/repository-policy.en.md) — **repositories must be licensed** unless that repo documents an approved exception. If the repo root has its own `LICENSE`, that license applies to that repo.
2. For documentation, follow [i18n policy](docs/i18n/POLICY.en.md) (English + Turkish for user-facing text).

## Workflow

1. Fork or branch from the default branch named in the target repository.
2. Keep changes focused; match existing style and tooling.
3. Open a pull request with a clear summary and test notes.
4. Policy changes in `.github` must update **both** EN and TR paired files.

## Code of conduct

Contributors are expected to follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
