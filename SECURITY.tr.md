# Güvenlik politikası

**Kuruluş:** xrystal-tech

## Desteklenen sürümler

Güvenlik düzeltmeleri, org README veya depo `README.md` içinde aktif bakımı belirtilen depolar için sağlanır. Arşivlenen depolarda düzeltme bakımcının takdirine bağlıdır.

## Güvenlik açığı bildirimi

**İstismar edilebilir güvenlik sorunları için lütfen kamuya açık GitHub issue açmayın.**

1. Mümkünse etkilenen depoda [GitHub özel güvenlik açığı bildirimi](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) kullanın.
2. Aksi halde o deponun `README.md` dosyasındaki bakımcılarla iletişime geçin veya bakımcılar yayınladıysa yalnızca belirtilen **Security** kanalını kullanın.

Bildirimde şunlar olsun:

- Etkilenen depo ve sürüm veya commit
- Yeniden üretme adımları
- Biliniyorsa etki değerlendirmesi

Bildirimlere **7 gün** içinde yanıt vermeyi hedefleriz; açıklama sürecini sizinle koordine ederiz.

## İyi niyetli araştırma

Bu politikaya uyan, gizliliği ihlal etmeyen, hizmeti gereksiz yere bozmayan ve sorunu göstermek için gerekli ölçünün ötesinde veri sızdırmayan iyi niyetli güvenlik araştırmasını destekleriz.
