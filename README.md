## Default license template

New repositories without an explicit license decision should add the org default from [license-templates/LICENSE-MIT](license-templates/LICENSE-MIT). If a repository already defines a different `LICENSE` or `LICENSE.md` (for example Apache-2.0), **that file governs that repository**—see the repository policy.

## Applying these policies

1. Create or use `xrystal-tech/.github` on GitHub.
2. Copy this repository’s contents into it (or mirror this repo).
3. Add repository-specific overrides only in the target repo’s `LICENSE`, README, or a local `POLICY.override.md` linked from the README.

Questions and change requests: open an issue in `xrystal-tech/.github` with the **organization-policy-change** label (if configured) or contact the org owners.
