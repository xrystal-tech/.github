# Gizlilik politikası — Xrystal (xrystal-tech) (GitHub kuruluşu)

**Yürürlük:** 2026-11-14  
**Kapsam:** `xrystal-tech` altındaki GitHub depoları, kuruluş sayfaları ve bu depolardan yayımlanan dokümantasyon.

## Özet

Xrystal açık kaynak depoları GitHub üzerinde barınır. GitHub, hesap ve kullanım verilerini [GitHub gizlilik bildirimi](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) kapsamında işler. Bu belge, proje bağlamında tipik olarak ne topladığımızı ve nasıl kullandığımızı açıklar.

## Topladıklarımız

Depoya bağlı olarak şunları işleyebiliriz:

- **GitHub profil ve katkı üst verisi** (kullanıcı adı, commit, issue, pull request) — GitHub’da görünen bilgiler.
- Issue, tartışma veya depodan bağlantı verilen anketlerde **gönüllü verdiğiniz bilgiler**.
- Depoya bağlı CI/CD veya dağıtım platformlarından **teknik günlükler** (derleme günlükleri, artefakt üst verisi) — proje bazında yapılandırılır.

Org depolarını, özel bir proje README ve gizlilik notunda belgelemedikçe **hassas kişisel veri toplamak için kullanmayız**.

## Bilgileri nasıl kullanırız

- Yazılım ve dokümantasyonu işletmek ve geliştirmek.
- Issue, güvenlik bildirimi ve katkılara yanıt vermek.
- Gerektiğinde yasal yükümlülüklere uymak.

xrystal-tech depoları üzerinden toplanan kişisel veriyi satmayız.

## Üçüncü taraflar

Tek tek depolar analitik, hata raporlama veya paket kayıtları kullanabilir. Kullanıcı veya katkı veren verisi işleyen hizmetler README’de belgelenmelidir.

## Haklarınız

Haklar yargı bölgenize ve GitHub’ın platform verisi için rolüne bağlıdır. Yalnızca GitHub’da işlenen veriler için GitHub kaynaklarına bakın. Bir depoda belgelenen proje özel işleme için o deponun README veya SECURITY dosyasındaki sorumlularla iletişime geçin.
