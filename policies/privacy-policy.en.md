# Privacy policy — Xrystal (xrystal-tech) (GitHub organization)

**Effective:** 2026-11-14  
**Applies to:** GitHub-hosted repositories and organization pages under `xrystal-tech`, and documentation published from those repositories.

## Summary

Xrystal open-source repositories are built on GitHub. GitHub processes account and usage data under [GitHub’s privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). This document describes what we typically collect in project context and how we use it.

## What we collect

Depending on the repository, we may process:

- **GitHub profile and contribution metadata** (username, commits, issues, pull requests) as visible on GitHub.
- **Information you voluntarily provide** in issues, discussions, or surveys linked from a repository.
- **Technical logs** from CI/CD or deployment platforms connected to a repository (build logs, artifact metadata), configured per project.

We do **not** use org repositories to collect sensitive personal data unless a specific project documents that need in its own README and privacy notice.

## How we use information

- Operating and improving software and documentation.
- Responding to issues, security reports, and contributions.
- Complying with legal obligations where applicable.

We do not sell personal data collected through xrystal-tech repositories.

## Third parties

Individual repositories may use third-party services (analytics, error reporting, package registries). Each repository should document such services in its README when they process user or contributor data.

## Your rights

Rights depend on your jurisdiction and GitHub’s role as a processor/controller for platform data. For data handled only on GitHub, refer to GitHub’s privacy resources. For project-specific processing documented in a repository, contact the maintainers listed in that repository’s README or SECURITY file.

## Children

Org repositories are not directed at children under 13 (or the applicable age in your region). We do not knowingly collect children’s personal information through these projects.

## Changes

We may update this policy. Material changes will be reflected in this file with an updated effective date; paired Turkish text will be updated in [privacy-policy.tr.md](privacy-policy.tr.md).

## Contact

Open a security or privacy question as described in [SECURITY.md](../SECURITY.md), or contact organization owners via GitHub.
