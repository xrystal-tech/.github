## Varsayılan lisans şablonu

Açık lisans kararı verilmemiş yeni depolar, kuruluş varsayılanını [license-templates/LICENSE-MIT](license-templates/LICENSE-MIT) dosyasından eklemelidir. Bir depoda farklı bir `LICENSE` veya `LICENSE.md` tanımlıysa (örneğin Apache-2.0), **o dosya o depoyu bağlar** — ayrıntılar depo politikasında.

## Politikaların uygulanması

1. GitHub’da `xrystal-tech/.github` oluşturun veya kullanın.
2. Bu deponun içeriğini oraya kopyalayın (veya bu depoyu yansıtın).
3. Depoya özel istisnaları yalnızca hedef deponun `LICENSE`, README dosyasında veya README’den bağlantılı yerel `POLICY.override.md` içinde verin.

Sorular ve değişiklik talepleri: `xrystal-tech/.github` içinde issue açın veya kuruluş sahipleriyle iletişime geçin.
