# License templates

| Template | When to use |
| --- | --- |
| [LICENSE-MIT](LICENSE-MIT) | **Org default** for new public repos when no other license is specified |
| Apache-2.0 | When a repository README or maintainer instruction says to use **Apache License 2.0** — copy the [official Apache 2.0 text](https://www.apache.org/licenses/LICENSE-2.0.txt) into the repo root as `LICENSE` and keep the SPDX header in source files as required |

Per [repository policy](../policies/repository-policy.en.md), the file at the **repository root** always wins over org defaults.
